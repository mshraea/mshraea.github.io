# Shubham Mishra — Portfolio Website

A responsive, static personal portfolio designed for GitHub Pages. It uses HTML, CSS and a tiny JavaScript file; no build tools or paid hosting are required.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `profile-photo.jpg` — your professional portrait
- `resume.pdf` — the CV file linked by the website (keep the filename exactly `resume.pdf`)

## Before publishing

1. Review every role title and bullet in `index.html` against your final resume.
2. Keep your working CV PDF in the repository root and name it exactly `resume.pdf` so both download links work.
3. Confirm your contact details and LinkedIn URL are correct.
4. Do not add confidential Amazon data, seller information, internal dashboards, or metrics that you do not have permission to disclose.
5. The site currently avoids specific quantified achievements because verified figures were not supplied with this build. Add metrics only if you can substantiate them.

## Publish with GitHub Pages (free)

1. Sign in to GitHub or create an account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`, replacing the placeholder with your GitHub username. For example, if your username were `shubhammishra`, the repository would be `shubhammishra.github.io`.
3. Unzip this project on your computer.
4. In your existing repository, select **Add file → Upload files** and upload the updated `index.html`, `style.css`, `README.md`, and `profile-photo.jpg`. Keep `script.js` and your working `resume.pdf` in the repository. Upload the files themselves, not the containing folder.
5. Commit the upload to the `main` branch.
6. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save** if needed.
7. Wait a few minutes and open `https://YOUR-GITHUB-USERNAME.github.io/`.
8. Test the site on your phone and computer. Test email, phone, LinkedIn, and CV links.

Official guide: https://docs.github.com/en/pages/quickstart

## Updating your website

Edit `index.html` to update text. Upload the edited file to the same repository and commit the change. GitHub Pages will publish the update automatically after deployment finishes.

## Notes

- Google Fonts are loaded from Google Fonts when available; the site falls back to common system fonts if not.
- If you prefer not to publish your phone number, remove the `tel:` links and displayed number from `index.html` before uploading.
- A public portfolio can be indexed by search engines. Publish only information you are comfortable sharing publicly.
