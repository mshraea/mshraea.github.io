# Shubham Mishra — Portfolio Website

A responsive personal portfolio designed for GitHub Pages. The design is built around the resume's verified experience, outcomes, and education.

## Files
- `index.html` — page content and portfolio sections
- `style.css` — custom visual system and responsive layout
- `script.js` — mobile navigation
- `profile-photo.jpg` — professional portrait
- `resume.pdf` — downloadable CV; keep this filename exactly as written

## Publish / update
1. Upload `index.html`, `style.css`, `script.js`, `profile-photo.jpg`, `README.md`, and the CV file named `resume.pdf` to the root of the `mshraea.github.io` repository.
2. Commit the changes to `main`.
3. Wait for GitHub Pages to deploy, then refresh `https://mshraea.github.io/` with Ctrl+F5.

## Content note
Career dates, roles, and metrics on the site are based on the resume provided by Shubham Mishra. The self-service reporting benefits are described as projected, and confidential internal information is not published.
